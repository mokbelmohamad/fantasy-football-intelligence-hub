# `js/api.js`

## Purpose

Compatibility export bridge for the provider API directory.

## Responsibilities
- Re-export public functions from js/api/index.js.

## Dependencies
- `api/index.js`

## Used by
- Legacy or future imports expecting js/api.js

## Maintenance notes
- New code should normally import from js/api/index.js or a specific provider module.

## Version baseline

Documented for Fantasy Football Intelligence Hub Version 2.2.1. This documentation reflects the merged feature set and does not change `APP_VERSION`.
